# 教材制作フロー

アプリ本体の機能追加ではなく、Re:Invent Reader の教材データを修正・追加するための標準手順。

## 1. 対象を決める

- 既存動画では、修正対象の時間範囲を決める。
- 新しい動画では、YouTube の動画 ID、タイトル、分類、利用条件を確認する。
- 動画・字幕・翻訳・サムネイルを扱う前に、公開・利用の条件を確認する。

## 2. transcript を整える

1. 音声と既存 transcript を照合し、聞き取り違い・脱落・タイムコードのずれを修正する。
2. 文の途中で切れている字幕は、まず意味の通る一文へ結合する。
3. 長い一文だけを、意味のまとまりと音読のしやすさを基準に分割する。
4. 英語文が確定してから、日本語訳を対応する単位に整える。
5. 各項目で `start`、`end`、英語文、日本語訳が同じ範囲を指すことを確認する。

時間の長さだけで機械的に分割しない。一息で音読でき、意味が途中で切れないことを優先する。

## 3. チャプターを整える

- 章は概ね5分を目安にしつつ、話題の切れ目を優先する。
- 各章に短く内容が分かるタイトルを付ける。
- 章の開始時刻が、対応する transcript の文へ自然につながることを確認する。

## 4. 新しい動画を追加する

1. transcript ファイルを `transcripts/` に追加する。
2. `videos.json` に動画メタデータ、transcript のパス、チャプターを追加する。
3. 動画一覧から開けること、Reader で字幕・言語切替・文選択・チャプター選択が動くことを確認する。

## 5. 確認と記録

- 修正した範囲で、連続再生・リピーティング・文選択・チャプター選択を確認する。
- 実機で確認できない項目は、未確認として記録する。
- 1本の動画、または意味のある修正単位ごとにコミットする。
