# 開発の進め方

## 基本の流れ

1. 通常は [教材制作フロー](content-workflow.md) に沿って、`videos.json` または `transcripts/` を更新する。
2. アプリ本体の仕様・構造を変える必要がある場合だけ、先に `docs/product/` の仕様を更新する。
3. 設計上の選択が必要なら、`docs/decisions/` を作成し、短い決定記録を追加する。
4. 変更に見合う確認を行う。再生ロジック、チャプター、字幕データの変更時は、関連する操作をまとめて確認する。
5. 実行方法や利用者向けの説明に影響する場合は README に反映する。

## 現在の確認観点

- 動画一覧から Reader を開けること。
- 字幕の英語・日本語切替、文の選択、チャプター選択が正しく同期すること。
- 連続再生とリピーティングで、現在の文と再生状態が正しく更新されること。
- モバイル画面で、固定コントロールとチャプター一覧が操作できること。
