# プロダクト仕様

最終更新: 2026-10-10

## プロダクトの一文説明

AWS re:Invent の動画を、技術英語の読み・聞き・音読を練習できる文単位の教材に変換する Web アプリ。

## 目的と対象

- AWS re:Invent の内容に関心があり、技術的な英語を学びたい人が対象。
- 動画をただ視聴するのではなく、興味のある話題に移動し、英文を聞き、読み、繰り返し発話できることを目指す。
- 特に、動画を見ずに文単位の音読練習へ集中する利用も支える。

## 現在の提供価値

- YouTube 動画とタイムスタンプ付き transcript を同期して表示する。
- 字幕を英語・日本語で切り替え、聞く・読む・意味を確認する学習を支える。
- リピーティング再生により、各文のあとに発話する時間を作る。
- チャプターから関心のある話題へ移動できる。

## 現在の教材

- AWS re:Invent 2025 — Keynote with Dr. Werner Vogels
- 動画長: 1:14:52
- チャプター: 16件
- transcript: 649項目

## 画面と機能

### 動画一覧

- 登録済み教材をカード形式で表示する。
- 各カードには、YouTube のサムネイル、分類、タイトル、チャプター数、動画時間を表示する。
- カード選択で、対象教材の Reader 画面を開く。

### Reader

- 動画、現在のチャプター、transcript、再生コントロールを表示する。
- transcript は文単位で表示し、再生位置に応じて現在の文を強調・追従表示する。
- 文を選択すると、その開始時刻へ移動して再生する。
- 字幕言語は英語と日本語を切り替えられる。
- 動画の表示・非表示を切り替えられる。非表示でもチャプター選択と文単位の学習を行える。

### 再生モード

- **連続再生**: 通常どおり動画を再生し、現在の文を追従表示する。
- **リピーティング再生**: 文の終了直前で一時停止し、文の長さに応じた発話時間の後、次の文から再開する。
- リピーティングでは、次の文の音声が混入しないことと、文末が不自然に欠けないことを重視する。

### チャプター

- 動画と transcript の間に、現在の章番号・章名・章の長さを表示する。
- チャプターバーを開くと、Bottom Sheet 形式で章一覧を表示する。
- 一覧では、章番号・章名・章の長さ・現在の章を示す。
- 章を選ぶと章の開始位置へ移動し、対応する文と画面表示を更新する。選択前に再生中であれば、移動後も再生を継続する。
- チャプターは概ね5分を目安にしつつ、時間による機械的な分割より話題の区切りを優先する。

## UI / UX 方針

- モバイルでの利用を優先する。
- 下部の再生コントロールは固定表示とする。
- 再生モードと言語は、選択状態が一目で分かる表示にする。
- 現在の文を読みやすく強調し、周辺の文は控えめに表示する。
- 大きな見た目の変更より、既存の学習フローを保った改善を優先する。

## データ仕様

- `videos.json` は、動画 ID、キー、タイトル、分類、transcript のパス、チャプターを管理する。
- `transcripts/*.json` は、文ごとの開始・終了時刻、英語文、日本語訳を管理する。
- 字幕を統合・分割する際は、`start`、`end`、英語文、日本語訳の意味上の整合性を保つ。
- 文途中で分かれた字幕は、リピーティング向けの再分割を行う前に、まず完全な一文として扱う。

## 技術・配布方針

- HTML、CSS、JavaScript によるビルド不要の静的サイトとして維持する。
- YouTube IFrame Player API を利用する。
- GitHub Pages で公開し、PWA として利用できるようにする。
- 新しいバックエンド、認証、データ保存先、ビルドツールは、必要性と運用コストを確認してから導入する。
