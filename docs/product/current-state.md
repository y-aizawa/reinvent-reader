# 現状・引き継ぎメモ

最終更新: 2026-10-10

## 現在わかっていること

- プロダクト名: Re:Invent Reader
- 目的: AWS re:Invent の動画を使った英語学習教材を作る Web アプリ
- 以前の開発場所: ChatGPT と GitHub
- GitHub リポジトリ: `y-aizawa/reinvent-reader`（`main` をローカルへ取り込み済み）
- 公開先: GitHub Pages — https://y-aizawa.github.io/reinvent-reader/
- 実装方式: ビルド不要の静的サイト（HTML / CSS / JavaScript）
- 外部連携: YouTube IFrame Player API
- 配布形態: GitHub Pages と PWA

## 実装済み機能

- 動画一覧とサムネイルの表示
- 動画とタイムスタンプ付き transcript の同期表示
- 字幕の英語・日本語切替と、文を選択して動画位置へ移動する操作
- 連続再生と、文ごとに停止して再開するリピーティング再生
- チャプターの表示・選択、動画表示の切替、画面スリープ抑止
- 現在の教材: AWS re:Invent 2025 の Dr. Werner Vogels キーノート 1 本
