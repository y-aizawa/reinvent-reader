## 確認済みの現状

- GitHub リポジトリは `y-aizawa/reinvent-reader`、公開先は GitHub Pages。
- ビルド不要の HTML / CSS / JavaScript による静的サイトで、YouTube IFrame Player API を使う。
- 教材は1本。AWS re:Invent 2025 の Dr. Werner Vogels キーノートで、動画長は 1:14:52、チャプター数は16。
- transcript は `transcripts/werner-vogels-2025.json` にあり、659件の文からなる。
- 字幕の英語・日本語切替、文を選んだ位置へのシーク、連続／リピーティング再生、チャプター選択、動画表示切替、Wake Lock を実装済み。
- チャプターは時間で機械的に分割せず、概ね5分を目安に話題の区切りを優先する方針。
